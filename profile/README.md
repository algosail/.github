# Algosail

Algosail builds small, composable JavaScript libraries for functional programming — tools that are easy to reason about, test, and combine.

## Libraries

| Package | Description |
|---------|-------------|
| [@algosail/array](https://github.com/algosail/array) | FP utilities for working with arrays |
| [@algosail/boolean](https://github.com/algosail/boolean) | FP utilities for working with boolean values |
| [@algosail/date](https://github.com/algosail/date) | FP utilities for working with date values |
| [@algosail/either](https://github.com/algosail/either) | The Either monad — a value that is either a failure (Left) or a success (Right) |
| [@algosail/fn](https://github.com/algosail/fn) | Function combinators for point-free, pipeable code |
| [@algosail/logic](https://github.com/algosail/logic) | Logical connectives and boolean control-flow combinators |
| [@algosail/maybe](https://github.com/algosail/maybe) | The Maybe monad — safe handling of absent values |
| [@algosail/nil](https://github.com/algosail/nil) | FP utilities for working with nullable values |
| [@algosail/number](https://github.com/algosail/number) | FP utilities for working with numbers |
| [@algosail/pair](https://github.com/algosail/pair) | FP utilities for working with pairs |
| [@algosail/regexp](https://github.com/algosail/regexp) | FP utilities for working with regular expressions |
| [@algosail/stream](https://github.com/algosail/stream) | Reactive stream library — lazy, pull-on-subscribe, and async-by-default |
| [@algosail/string](https://github.com/algosail/string) | FP utilities for working with strings |
| [@algosail/strmap](https://github.com/algosail/strmap) | FP utilities for working with plain objects as maps |
| [@algosail/styles](https://github.com/algosail/styles) | Scoped CSS via tagged template literals |
| [@algosail/dom](https://github.com/algosail/dom) | Reactive DOM framework built on `@algosail/stream` |
